METU EE493 / EE494 Project

Autonomous Parking & Recall System

AutoNexa is a low-cost indoor autonomy prototype with live LiDAR mapping, vehicle-like navigation, mobile control, and layered safety.

Watch Demo View Results Open Poster

No markers. No pre-mapping. Phone-only operation.

Overview

What AutoNexa Does

The system combines sensing, navigation, embedded control, and a mobile app into one small-scale autonomous parking platform.

Autonomous Parking

The vehicle drives to selected parking bays and performs the maneuver without manual control.

Vehicle Recall

The user can command the robot to return to a saved recall point from the mobile app.

Live Environment Awareness

LiDAR-based perception helps the robot understand the indoor test area and avoid obstacles.

Mobile Operator Console

The app supports manual driving, goal selection, waypoint storage, monitoring, and E-STOP.

Architecture

A Simple, Safe Control Chain

AutoNexa follows a layered structure: sensing first, decision-making next, and actuator commands only after safety checks.

01

Sense

LiDAR scans the indoor test environment.

02

Map

The robot builds and updates a live map.

03

Plan

The navigation stack selects vehicle-like routes.

04

Check

Commands pass through software and firmware safety layers.

05

Move

The embedded controller drives steering and motors.

Failure Insight

Failures are geometric, not random.

Remaining fails mainly appear in long cross-map routes, reverse back-in maneuvers, obstacle-adjacent narrow approaches, and final goal-tolerance overshoot.
