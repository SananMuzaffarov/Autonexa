METU EE493 / EE494 Project

Autonomous Parking & Recall System

AutoNexa is a compact autonomous vehicle prototype that maps its surroundings, parks itself, and returns to a selected position through a mobile operator console.

Watch Demo View Results

Live mapping, autonomous parking, recall, and mobile control.

Overview

What AutoNexa Does

The system combines sensing, navigation, embedded control, and a mobile app into one small-scale autonomous parking platform.

Autonomous Parking

The vehicle drives to a selected parking slot and performs the maneuver without manual control.

Vehicle Recall

The user can command the robot to return to a saved position from the mobile app.

Live Environment Awareness

LiDAR-based perception helps the robot understand the indoor test area and avoid obstacles.

Mobile Operator Console

The app provides control, navigation commands, system status, and emergency stop access.

Architecture

A Simple, Safe Control Chain

AutoNexa follows a layered structure: sensing first, decision-making next, and actuator commands only after safety checks.

01

Sense

LiDAR scans the indoor test environment.

02

Map

The robot builds and updates a live map.

03

Plan

The navigation stack selects a safe route.

04

Check

Commands pass through software and hardware safety layers.

05

Move

The embedded controller drives the steering and motors.
