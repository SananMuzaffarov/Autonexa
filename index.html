01

System Overview

AutoNexa addresses autonomous navigation in constrained indoor parking environments — surveying the space, driving to designated slots, and recalling to user-defined locations on command.

Map-Free Exploration

Builds a live occupancy map using LiDAR-based SLAM Toolbox. No pre-saved map required — the robot surveys the environment on every session.

Layered Safety

6-layer safety pipeline from velocity smoother to hardware E-STOP latch. No planner output reaches motors without passing every stage.

Ackermann Kinematics

SMAC Hybrid-A* with REEDS_SHEPP model plans forward and reverse maneuvers. Minimum turning radius 0.50 m with conservative margin.

Mobile Operator Console

Flutter app communicates via Flask HTTP/WebSocket bridge. Full map view, waypoints, nav goals, live tuning, and E-STOP from your phone.

50 Hz Real-Time Control

Raspberry Pi Pico RP2040 runs deterministic firmware loop at 50 Hz. Independent watchdog and latching E-STOP on the embedded side.

4× Battery Margin

12.8 V / 7 Ah lead-acid pack delivers ~61 minutes endurance — over 4× the 15-minute requirement with sub-10% voltage sag under load.

Subsystems

Four tightly integrated subsystems working in concert.

Embedded Subsystem

Runs on Raspberry Pi Pico (RP2040, dual ARM Cortex-M0+). Firmware written in C with Pico SDK. A single 50 Hz hardware-timer loop is the only scheduling primitive.

Control Loop 50 Hz (20 ms)
Motor Driver L298N H-bridge
Steering Servo PWM 50 Hz
Motor PWM 10 kHz
Wheelbase 0.25 m
Max Steer ±30°
Encoder Res 1320 edges/rev
Timeout 200 ms

50 Hz Timer Loop

1 Read encoders (PIO quadrature decode)
2 Forward kinematics → odometry
3 Safety check (timeout, E-STOP, heartbeat)
4 Apply actuators (servo PWM + L298N)
5 Parse ASCII CLI / emit telemetry @ 10 Hz
